# book_store
# 📗 Basic SQL Queries

This section contains fundamental SQL queries for practice using a bookstore database.

---

## 🧠 Questions

1. Retrieve all books in the **"Fiction"** genre.

2. Find books published after the year **1950**.

3. List all customers from **Canada**.

4. Show orders placed in **November 2023**.

5. Retrieve the total stock of books available.

6. Find the details of the most expensive book.

7. Show all customers who ordered more than **1 quantity** of a book.

8. Retrieve all orders where the total amount exceeds **$20**.

9. List all genres available in the **Books** table.

10. Find the book with the lowest stock.

11. Calculate the total revenue generated from all orders.

---

## 📌 Notes
- These queries cover basic SQL operations such as filtering, sorting, and aggregation.
- Suitable for beginners practicing SQL on any relational database.
# 📘 Advanced SQL Queries

This repository contains a set of advanced SQL practice questions focused on a bookstore database.

---

## 🧠 Questions

1. Retrieve the total number of books sold for each category.

2. Find the average price of books in the **"Fantasy"** category.

3. List customers who have placed at least **2 orders**.

4. Retrieve the top 3 most expensive books in each category.

5. Find the total revenue generated from book sales.

6. List all customers who have never placed an order.

7. Retrieve the most popular book (highest quantity sold).

8. Find the total number of orders placed in each month.

9. List authors whose books have been sold at least once.

10. Retrieve customers who have spent more than the average total spending.

---

## 📌 Notes
- These queries are designed for practice with joins, aggregations, grouping, and subqueries.
- You can implement them using any SQL database such as MySQL, PostgreSQL, or SQL Server.
